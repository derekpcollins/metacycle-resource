# Code of Conduct

This project is a small community of Metacycle owners helping each other. Keep it useful and kind.

## Expected

- Be respectful and assume good faith, especially with newcomers and non-native English speakers.
- Give sources for claims and accept corrections gracefully.
- Disclose any commercial interest (for example, if you sell parts) when you contribute.

## Not acceptable

- Harassment, insults, or personal attacks.
- Spam, scams, or undisclosed self-promotion.
- Posting other people's private information.
- Deliberately false or dangerous repair advice.
