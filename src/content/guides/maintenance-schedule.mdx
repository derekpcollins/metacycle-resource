This schedule comes from section 20 of the Sondors owner's manual. Each interval is by mileage or by time, whichever comes first. In dusty or dirty conditions, do the checks more often. The manual splits these between owner inspections and "Sondors technician" service. With the company gone, everything falls to owners or an independent shop.

| Item            | What to check                                             | Every ride | 500 mi / 1 mo | 3,000 mi / 12 mo | 6,000 mi / 18 mo | 10,000 mi / 24 mo |
| --------------- | --------------------------------------------------------- | ---------- | ------------- | ---------------- | ---------------- | ----------------- |
| Brake fluid     | Level in the handlebar sightglasses; top up if below MIN  | ✓          | ✓             | ✓                |                  | ✓                 |
| Brake rotors    | Damage; at least 2 mm thick                               | ✓          | ✓             | ✓                |                  | ✓                 |
| Brake pads      | At least 3 mm (0.1 in) of friction material               | ✓          | ✓             | ✓                |                  | ✓                 |
| Brake levers    | Minimal free play (2–3 mm)                                | ✓          | ✓             |                  |                  |                   |
| Turn signals    | Work in both directions                                   | ✓          | ✓             |                  |                  |                   |
| Headlight       | High and low beam work                                    | ✓          | ✓             |                  |                  |                   |
| Shock absorbers | Work smoothly; no oil leaks                               | ✓          | ✓             | ✓                |                  | ✓                 |
| Fasteners       | All tight                                                 |            | ✓             |                  |                  |                   |
| Wheels          | Run-out and damage                                        |            | ✓             | ✓                |                  |                   |
| Tires           | Tread at least 2 mm; pressure (front 32 psi, rear 30 psi) | ✓          | ✓             |                  | ✓                |                   |
| Steering        | Smooth through full lock; steering nut not loose          | ✓          | ✓             |                  |                  |                   |
| Wheel bearings  | Turn smoothly; no leaking                                 |            | ✓             |                  | ✓                |                   |
| Kickstand       | Moves freely, springs back, locks up and down             | ✓          | ✓             |                  |                  |                   |
| Drive motor     | Runs smoothly                                             |            | ✓             |                  |                  |                   |

**Also, regardless of mileage:**

- **Replace the brake fluid every 12 months** with DOT 3 or DOT 4. See [Brake fluid & pad service](/guides/brake-service).
- Charge and store the battery as described in [Long-term storage](/guides/long-term-storage) and [Cold-weather charging](/guides/cold-weather-charging).

**Notes:**

- The manual's schedule table gives 32 psi for both tires; its tire page (and Metacyclopedia) give front 32 psi, rear 30 psi. We've used the tire page.
- The manual has no torque values, so "all fasteners tight" means snug, not to spec. Torque specs are on the [help wanted](/contribute/help-wanted) list.
