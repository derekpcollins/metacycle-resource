# Contributing

Thanks for helping keep Metacycles on the road. This guide is a stub; easier ways to contribute (issue forms and a no-account web form) arrive in a later phase.

## The rules that matter

1. **Every fact needs a source.** Add a link or a photo. Changes to specs or fixes without one are published as _community-reported_.
2. **Never guess.** If you don't know a value (URL, price, part number, torque), write `TODO`.
3. **Vendors don't edit their own listings** without saying so in the pull request.

## Making a change today

1. Find the file under `src/content/` (or use the "Edit this page" link on the site).
2. Edit it in GitHub's web editor. Saving opens a pull request.
3. The build checks your change automatically. If it fails, the error says which field is wrong.
4. The editor reviews and merges.

Run `npm run ci` locally before opening a pull request if you're working from a clone.
